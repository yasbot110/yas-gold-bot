## ۲. منابع قیمت — نتایج تست زنده

### 🥇 برنده: آینه‌های TGJU (تست شد، کار می‌کنه)

```
https://call2.tgju.org/ajax.json   ← HTTP 200 از خارج ایران!
https://call3.tgju.org/ajax.json   ← 200 (آینه پشتیبان)
https://call4.tgju.org/ajax.json   ← 200
https://call5.tgju.org/ajax.json   ← 200
```

- **بدون API key، بدون محدودیت شناخته‌شده، حجم ~۳۰۰KB** (۷۸۹ ابزار قیمتی)
- داده‌ی واقعی استخراج‌شده در زمان تحقیق:

| نماد | معنی | قیمت (ریال) |
|---|---|---|
| `price_dollar_rl` | دلار آمریکا | 1,999,000 |
| `price_eur` | یورو | 2,336,100 |
| `geram18` | طلای ۱۸ عیار (گرم) | 217,464,000 |
| `geram24` | طلای ۲۴ عیار | 289,949,000 |
| `sekee` | سکه امامی | 2,180,400,000 |
| `nim` | نیم سکه | 1,120,000,000 |
| `rob` | ربع سکه | 610,000,000 |
| `gerami` | سکه گرمی | 320,000,000 |
| `mesghal` | مثقال طلا | 942,050,000 |
| `ons` | انس جهانی (دلار) | 4,639.47 |

- ساختار هر آیتم: `p` = قیمت فعلی، `h/l` = سقف/کف روز، `d/dp/dt` = تغییر، `ts` = زمان دقیق به‌روزرسانی
- ⚠️ قیمت‌ها به **ریال** هستن — برای نمایش باید ÷۱۰ کنی و «تومان» نشون بدی
- ⚠️ فیلد `ts` بعضی موارد فقط تاریخ روزه؛ برای «لحظه‌ای بودن» timestamp سرخود رو ذخیره کن

```python
import httpx
async def get_prices():
    async with httpx.AsyncClient(timeout=15) as c:
        d = (await c.get("https://call2.tgju.org/ajax.json")).json()["current"]
    return {
        "usd": int(d["price_dollar_rl"]["p"].replace(",", "")) // 10,      # تومان
        "gold18": int(d["geram18"]["p"].replace(",", "")) // 10,
        "coin": int(d["sekee"]["p"].replace(",", "")) // 10,
        "updated": d["price_dollar_rl"]["ts"],
    }
```

## ۳. راه‌حل «منبعم کانال تلگرامه»

**تست انجام شد:** `t.me/s/<channel>` برای کانال‌های عمومی معمولی (مثل @durov) جواب می‌ده، ولی برای **@tgju و @alanchand پیش‌نمایش وب غیرفعاله** (صفحه‌ی Contact برمی‌گرده).

پس دو راه داری:

### راه الف — Telethon (پیشنهادی) ✅
کتابخانه‌ی MTProto پایتون — مثل یک اکانت واقعی وارد کانال می‌شه و پیام‌ها رو می‌خونه:

```python
# pip install telethon
from telethon import TelegramClient, events

client = TelegramClient('session', API_ID, API_HASH)

@client.on(events.NewMessage(chats='@YOUR_PRICE_CHANNEL'))
async def handler(e):
    text = e.message.message          # متن پیام قیمت
    await parse_and_store(text)       # regex → عدد دلار/طلا → دیتابیس

client.start()
client.run_until_disconnected()
```

- `API_ID` و `API_HASH` رایگان از my.telegram.org → API development tools
- ⚠️ session file رو هرگز کامیت نکن؛ برای سرور باید بار اول لاگین کنی (کد ارسال می‌شه به اکانتت)
- مزیت: مستقل از هر سایت — فقط به کانال اعتماد می‌کنی
- نکته: Telethon روی Workers کلادفلر اجرا نمی‌شه — این بخش مال لایه‌ی پایتونیه (سرور/لوکال)

### راه ب — اگر کانالت پیش‌نمایش وب فعال باشه
`https://t.me/s/<channel>` → HTML حاوی `tgme_widget_message_text` → BeautifulSoup → آخرین پیام. بدون نیاز به API_ID. (برای کانال خودت که بسازی این ممکنه.)

## ۵. هاست رایگان — تحلیل Cloudflare (اعداد رسمی مستندات)

### Workers Free
| محدودیت | مقدار | برای پروژه‌ی تو |
|---|---|---|
| درخواست | ۱۰۰٬۰۰۰ در روز | سایت + API ربات: خیلی بیشتر از نیاز ✅ |
| CPU | 10ms در هر درخواست | fetch/JSON: ~۲ms مصرف متوسط worldwide ✅ |
| Cron Trigger | ۵ تا در هر اکانت، حداقل بازه ۱ دقیقه | پست قیمت هر ۵-۱۵ دقیقه: یک trigger کافیه ✅ |
| Subrequest | ۵۰ در هر invocation | هر اجرا ۱-۲ fetch + ۲-۳ KV op ✅ |

### Workers KV Free
- ۱۰۰٬۰۰۰ خواندن/روز + **۱٬۰۰۰ نوشتن/روز**
- ⚠️ نکته‌ی مهم: قیمت رو هر دقیقه در KV بنویسی، سقف نوشتن پر می‌شه (۱۴۴۰ نوشتن/روز!). پس: cron هر ۵-۱۵ دقیقه بنویسه (۹۶-۲۸۸ نوشتن) یا فقط وقتی قیمت تغییر کرد.

### D1 (SQLite ابری) Free
- ۱۰ دیتابیس × ۵۰۰MB + ۵ میلیون خواندن/روز — برای جدول سفارش‌ها و تاریخچه قیمت عالی ✅

### Pages Free
- هاست نامحدود سایت استاتیک + ۵۰۰ build/ماه — فرانت سایت فروشت اینجا ✅
- دامنه‌ی رایگان: `xxx.pages.dev` و `xxx.workers.dev` — حتی بدون خرید دامنه، هزینه‌ی واقعی: **۰**

### نقش‌ها در معماری
```
CF Worker A (cron */10 * * * *)  →  fetch TGJU  →  بنویس KV + D1(history)
CF Worker B (webhook bot)        →  telegram webhook → پاسخ /price, ثبت سفارش
CF Pages (سایت)                  →  UI انتخاب طلای مشتری → POST به Worker B
Worker B → D1 (ذخیره سفارش) + sendMessage به ADMIN_ID
```

### جایگزین‌های رایگان/ارزان برای لایه‌ی پایتون
| سرویس | وضعیت |
|---|---|
| **Render free** | وب‌سرویس رایگان با sleep بعد بی‌کاری — webhook تلگرام رو بیدار می‌کنه، قابل قبول برای MVP |
| **Fly.io** | پلن رایگان محدود شده؛ برای ماشین‌های کوچک هنوز خیلی ارزون |
| **Oracle Cloud Always Free** | VPS واقعی ARM (۴ هسته/۲۴GB) — سخاوتمندترین، ولی ثبت‌نام از ایران نیاز به کارت بین‌المللی داره |
| **VPS ایرانی ارزان** (~۱۰۰-۲۰۰ هزار تومان/ماه) | پینگ عالی به TGJU/Nobitex، بدون مشکل تحریم — گزینه‌ی عملی نهایی |

## ۶. معماری پیشنهادی نهایی (هزینه: ۰ تومان)

```
                    ┌──────────────────────────────────────┐
                    │           CLOUDFLARE (FREE)          │
                    │                                      │
 کانال مرجع ──────▶ │ Worker-CRON هر ۱۰ دقیقه              │
 (@tgju یا TGJU)    │  fetch ajax.json ─▶ KV(قیمت فعلی)    │
                    │                  └─▶ D1(تاریخچه)     │
                    │                                      │
 Telethon/اسکرپ ──▶ │ Worker-BOT (webhook)                 │
 (لایه پایتون تو)   │  /start /price /gold /order          │
                    │  سفارش جدید ─▶ D1 + پیام به ادمین    │
                    │                                      │
                    │ Pages: سایت فروش (RTL، وزیرمتن 😊)   │
                    │  UI مقدار طلا ─▶ POST /api/order     │
                    └──────────────────────────────────────┘
                              │
        ادمین: پیام تلگرام (مقدار + قیمت لحظه + شماره تماس مشتری)
```

**چرا این ترکیب؟**
1. بخشی که باید ۲۴/۷ روشنه (جمع‌آوری قیمت، وب‌هوک ربات، سایت) روی زیرساخت رایگان و بدون‌خوابی کلادفلره
2. بخش پایتون (Telethon + تحلیل) جایی نصبه که تو کنترلش داری — لوکال برای شروع، بعداً VPS
3. هیچ نقطه‌ی خرابی تک‌گانه نیست: اگر TGJU قطع شد → Nobitex؛ اگر کانال قطع شد → API مستقیم

## ۸. ریسک‌ها و نکات

1. **KV نوشتن روزانه** — فقط تغییرات رو بنویس (diff با مقدار قبلی)
2. **قیمت ریال vs تومان** — همیشه واحد رو صریح کن؛ اشتباه ×۱۰ فاجعه‌ی مالی تو فروش طلاست!
3. **اعتبار منبع**: TGJU بازار آزاد تهران رو نشون می‌ده؛ برای فروش واقعی طلا حاشیه‌ی امنیت (spread) خودت رو روی قیمت بذار
4. **تحریم/دسترسی**: Nobitex و برخی سرویس‌ها IP خارج رو می‌بندن — تست نهایی باید از داخل ایران باشه (سرور من نمی‌تستست، تو می‌تونی)
5. **حریم خصوصی**: شماره تماس مشتری‌ها = داده شخصی؛ در D1 رمز نگه‌دار و دسترسی ادمین محدود باشه
6. **Telethon session** = کلید اکانتت؛ هرگز پابلیک نکن
