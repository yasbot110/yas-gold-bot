## ۱. تحلیل عمیق ریپوهای گیت‌هاب

### 🏆 iamashkan/CurrencyRateTelegramBot — «دوقلوی پروژه تو» (MIT ✅)

کل سورس (۳۴۷ خط JS) خونده شد. **چون MIT لایسنس داره می‌تونی قانوناً براش فورک بزنی و فارسی‌سازیش کنی.**

**معماری کامل:**
```
worker.js (تک‌فایل!)
├── fetch()      ← /preview (پیام بدون HTML)، /trigger (ارسال دستی)، /analysis (جمع‌بندی)
├── scheduled()  ← cron */15 دقیقه از wrangler.toml
├── ITEMS        ← لیست ابزارها: price_dollar_rl, geram18, crypto-tether-irr, ons...
├── fetchAllPrices() ← GET call2.tgju.org/ajax.json + ÷10 (ریال→تومان)
├── KV "PRICE_STORE"
│     ├── last_night          ← snapshot ساعت ۲۳ برای مقایسه روز بعد
│     ├── analysis_sent_{date}← جلوگیری از ارسال تکراری (TTL 48h)
│     └── api_down            ← پرچم سلامت + نوتیفیکacion به ادمین
└── handleSchedule()
      ├── ساعت ۲۳ تهران → جمع‌بندی پایان روز (کمترین/بیشترین هر ابزار)
      └── ۸≤ساعت<۲۳ → پست ساکت (silent) هر ۱۵ دقیقه
```

**ترفندهای ارزشمند (کپی‌شده از سورس واقعی):**

| ترفند | پیاده‌سازی |
|---|---|
| RTL درست در تلگرام | کاراکتر `RLM` (U+200F) اول هر خط + عدد داخل `LRI...PDI` تا مخلوط نشه |
| اعداد فارسی | تبدیل با جدول `FA_DIGITS` |
| تاریخ شمسی | `Intl.DateTimeFormat("en-US-u-ca-persian")` — بدون کتابخانه! |
| دایره جهت قیمت | مقایسه با snapshot دیشب → 🟢 بالا / 🔴 پایین / ⚪️ بی‌تغییر |
| صرفه‌جویی KV | فقط ۲ کلید دائمی + کلید روزانه با TTL |
| مانیتور سلامت | خطا → نوتیف ادمین؛ رفع خطا → نوتیف «وصل شد» |

**چیزهایی که خودت باید اضافه کنی (نقطه تمایزت):**
1. **D1** برای تاریخچه (ashkan فقط آخرین شب رو نگه می‌داره)
2. **Webhook سفارش** (ربات فعلی فقط publish می‌کنه، تعاملی نیست)
3. **Failover چندمنبعی** (اگر ajax.json خطا داد → Nobitex/Wallex)
4. Throttle نوشتن KV: بنویس فقط وقتی قیمت واقعاً تغییر کرد

### ❌ کانال‌های بدون پیش‌نمایش (نیاز به Telethon)

`@tgju` • `@alanchand` • `@e_tgju` • `@TehranGoldUnion` — صفحه Contact برمی‌گردونن. با MTProto (Telethon) قابل خوندن هستن چون عضویت در کانال عمومی محدودیتی نداره.

### 🕌 وضعیت خاص مشهد

- **کانال تلگرامی اختصاصی زنده‌ی بازار مشهد با پیش‌نمایش فعال پیدا نشد** (اسم‌های محتمل تست شد: mashhadgold, goldmashhad=تبلیغ نمایشگاه, talamashhad, khorasangold...)
- نرخ رسمی مشهد توسط **اتحادیه طلا و جواهر مشهد** اعلام می‌شه (مثلاً ساعت ۱۱:۰۰ روزانه — تأیید شده در خبرگزاری mashhadfori)
- سایت‌های قیمت زنده مشهد (hildatejarat.com و احتمالاً سایت اتحادیه) از سرور خارج ایران **قابل دسترسی نیستن** — تو از داخل ایران تست کن
- 💡 راه‌حل عملی: نرخ مشهد معمولاً چند واحد تفاوت جزئی با تهران داره → یا ضریب/spread شهرستان روی نرخ تهران بذار، یا روزانه یک بار نرخ اتحادیه مشهد رو دستی/Telethon وارد سیستم کن

### 🔮 درباره «قیمت فردا»

- کانال تلگرامی معتبرِ اختصاصی «قیمت فردا» وجود نداره — این محتوا تحلیلیه، نه داده
- تحلیل‌های پیش‌بینی در: اخبار tgju.org (تگ پیش‌بینی قیمت طلا)، دنیای اقتصاد، اقتصادنیوز
- ⚠️ توصیه مهندسی: برای **قیمت‌گذاری فروش** هیچ‌وقت از پیش‌بینی استفاده نکن؛ فقط قیمت لحظه + حاشیه امن خودت. اگر خواستی ویژگی جذاب «انتظارات بازار» رو نشون بدی، می‌شه RSS خبرگزاری‌ها رو خلاصه کرد (بدون عدد قطعی)
