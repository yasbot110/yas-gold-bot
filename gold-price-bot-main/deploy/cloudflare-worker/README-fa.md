# راهنمای دیپلوی دستی روی کلادفلر (بدون نصب هیچ چیز روی کامپیوتر)

هدف: ربات قیمت طلا **روی سرورهای کلادفلر** اجرا بشه — بدون کامپیوتر روشن، رایگان.
این نسخه، همون منطق نسخه‌ی لوکال پایتونی است (فقط به زبان JS برای ورکر).

> ⏱ زمان لازم: حدود ۱۰ دقیقه. همه‌ی کارها تو مرورگر.

---

## قدم ۱ — ساخت Worker

1. برو به [dash.cloudflare.com](https://dash.cloudflare.com) و لاگین کن
   (اگه اکانت نداری با ایمیل ثبت‌نام کن — فقط ایمیل می‌خواد).
2. از منوی چپ: **Compute & AI → Workers & Pages**
3. دکمه‌ی **Create** → تب **Start with Hello World!** → **Deploy** را نزن!
   اول روی **Edit code (رفتن به ادیتور)** کلیک کن.

## قدم ۲ — کد را بچسبان

1. در ادیتور آنلاین، تمام محتوای `worker.js` پیش‌فرض را پاک کن.
2. **کل محتوای فایل `deploy/cloudflare-worker/worker.js`** (همان یک فایل، همه‌چیز داخلش است) را کپی و پیست کن.
3. اسم ورکر بالا سمت چپ را بگذار `gold-price-bot` → **Save and deploy**.
4. آدرس ورکر شبیه `https://gold-price-bot.<your-subdomain>.workers.dev` ساخته می‌شود — یادداشتش کن.

> 💡 کل کد عمداً در **یک فایل** ادغام شده تا با کپی‌پیست مستقیم تو داشبورد کار کند —
> هیچ import بین‌فایلی لازم نیست. کامنت‌ها انگلیسی‌اند؛ متن پیام‌های ربات فارسی می‌ماند.

## قدم ۳ — ساخت KV (حافظه‌ی ربات)

1. منوی چپ: **Storage & Databases → KV**
2. **Create namespace** → نام: `gold-bot-state` → Add.
3. برگرد به **Workers & Pages → gold-price-bot → Settings → Bindings** (یا Variables & Secrets)
4. **Add binding** → نوع **KV namespace** →
   Variable name: `STATE` ، Namespace: `gold-bot-state` → Save.

## قدم ۴ — متغیرها و توکن‌ها

همان صفحه‌ی **Settings → Variables and Secrets**:

| نوع | نام | مقدار |
|---|---|---|
| Secret | `BOT_TOKEN` | توکن ربات از @BotFather (همان که لوکال داری) |
| Secret | `ADMIN_IDS` | آی‌دی عددی خودت (مثل `306652923`) |
| Secret | `SECRET_TOKEN` | یه رشته‌ی تصادفی دلخواه (برای امنیت وب‌هوک) — مثلاً خروجی `openssl rand -hex 16` |

> کانال انتشار اینجا تعریف نمی‌شود؛ داخل KV کلید `state` → `settings.channel` ست می‌شود (قدم ۷ و بخش تنظیمات).

## قدم ۵ — کرن هر دقیقه

1. **Settings → Trigger Events → Cron Triggers** → **Add Cron Trigger**
2. عبارت `* * * * *` را وارد کن (هر دقیقه) → Save.
3. ⚠️ پلن رایگان: حداکثر ۵ کرن به ازای هر اکانت؛ هر دقیقه مشکلی ندارد.

## قدم ۶ — وصل کردن وب‌هوک تلگرام (برای /now /status /publish)

در cmd ویندوز (یک‌بار اجرا کن؛ `BOT_TOKEN` و آدرس ورکر و `SECRET_TOKEN` خودت را بگذار):

```bat
curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook" ^
  --data-urlencode "url=https://gold-price-bot.YOUR-SUBDOMAIN.workers.dev/" ^
  --data-urlencode "secret_token=<SECRET_TOKEN>" ^
  --data-urlencode "allowed_updates=[\"message\"]"
```

جواب باید `"ok":true` باشد.

## قدم ۷ — تست

1. به ربات در تلگرام `/now` بده → باید گزارش لحظه‌ای بیاید (از KV یا دریافت مستقیم).
2. صبر کن قیمت در کانال مارکیز عوض شود → باید «⬆️ تغییر قیمت …» برات بیاید.
3. اگر حالت خودکار روشن باشد و کانال انتشار تنظیم شده باشد، با اولین تغییر قیمت پست به کانال می‌رود.
4. لاگ‌ها: **Workers & Pages → gold-price-bot → Logs** → Live.

## تنظیماتی که فعلاً از داشبورد قابل تغییرند

نسخه‌ی ورکر پنل تعاملی ندارد؛ مقادیر زیر داخل KV کلیدِ `state` ذخیره می‌شوند:

```json
{
  "settings": {
    "auto_enabled": true,
    "channel": "@my_channel",
    "buy_deduction": 100000
  }
}
```

- **مدل قیمت:** فقط «فروش» از کانال مرجع گرفته می‌شود (ریال → ÷۱۰ → تومان)؛
  **خرید = فروش − `buy_deduction`** (پیش‌فرض ۱۰۰٬۰۰۰ تومان؛ تغییرش فقط دستی همین‌جا).
- همه‌ی قیمت‌ها با ارقام انگلیسی و واحد تومان نمایش داده می‌شوند.
- پست کانال دو دکمه دارد: «🔴 فروش به ما» (راست) و «🟢 خرید از ما» (چپ).
- رفتار انتشار ثابت است: **هر دقیقه چک؛ پست فقط وقتی «فروش» عوض شود و داخل
  ساعات کاری ۹:۳۰–۲۰:۰۰ تهران باشد** (قیمت ثابت یا بیرون بازه → هیچ).
- برای ویرایش: داشبورد → KV → gold-bot-state → کلید `state` را دستی ویرایش کن
  (یا بگو تا در نسخه‌ی بعد وب‌هوکِ پنل تنظیمات را هم کامل کنیم).

## هزینه و محدودیت پلن رایگان

| مورد | سهمیه | مصرف ما |
|---|---|---|
| درخواست Workers | 100,000/روز | ~۱۴۴۰ (کرن) + وب‌هوک |
| کرن تریگر | ۵ عدد/اکانت | ۱ |
| نوشتن KV | 1,000/روز | فقط موقع تغییر قیمت (~چند ده) |
| خواندن KV | 100,000/روز | ~۲×۱۴۴۰ |

✅ خیلی زیر سقف.

## اشکال‌زدایی

- **پستی به کانال نمی‌رود**: ربات باید در کانال ادمین باشد با دسترسی Post Messages.
- **`/now` جواب نمی‌دهد**: webhook را دوباره ست کن؛ Logs را چک کن.
- **خطای KV**: مطمئن شو binding نامش دقیقاً `STATE` است (بزرگ).
