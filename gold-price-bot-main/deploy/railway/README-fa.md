# 🚂 راهنمای دیپلوی ربات قیمت طلا روی Railway

این پوشه (`deploy/railway/`) یک نسخه‌ی **خودکفا** از همان ربات لوکال است با دو
تغییر مخصوص Railway:

1. **`DATA_DIR`**: اگر متغیر `DATA_DIR` تعریف کنی، دیتابیس و لاگ داخل همان
   مسیر نوشته می‌شود — آن را به Volume وصل می‌کنیم تا داده‌ها با هر دیپلوی
   پاک نشوند.
2. **وب‌سرور سلامت روی `$PORT`**: Railway برای سرویس‌های وب انتظار دارد پروسه
   روی `$PORT` گوش دهد؛ یک HTTP کوچک (فقط برای healthcheck) کنار polling
   بالا می‌آید.

---

## مرحله ۰ — پیش‌نیازها

- اکانت رایگان [railway.app](https://railway.app) (با GitHub لاگین کن)
- ریپوی خصوصی `gold-price-bot` که همه‌چیز درش کامیت شده

> ⚠️ نکته‌ی مهم درباره‌ی هزینه: پلن تریال فقط **۵$ اعتبار تا ۳۰ روز** است.
> این ربات حدود ~۲.۵–۳$/ماه مصرف دارد؛ بعد از اتمام تریال برای ادامه باید
> پلن Hobby (۵$/ماه) فعال شود — نیاز به کارت بین‌المللی دارد.

---

## مرحله ۱ — ساخت پروژه از ریپو (Deploy from GitHub repo)

1. برو به [railway.app/new](https://railway.app/new) → **Deploy from GitHub repo**
2. اولین بار، دکمه‌ی **Install App** را بزن و دسترسی به ریپو `gold-price-bot`
   بده (فقط همین ریپو کافی است).
3. ریپوی `alishahrestani2000/gold-price-bot` را انتخاب کن.

Railway خودش `requirements.txt` و `railway.json` را پیدا می‌کند و
`python -m bot` را به عنوان دستور شروع اجرا می‌کند.

> ⚠️ **مهم:** چون کل ریپو build می‌شود، Railway ممکن است فولدرهای دیگر را هم
> ببیند. اشکالی ندارد — `railway.json` داخل `deploy/railway/` فقط وقتی اعمال
> می‌شود که Root Directory سرویس را روی همین پوشه تنظیم کرده باشی (مرحله‌ی ۲).

---

## مرحله ۲ — تنظیم Root Directory

1. سرویس ساخته‌شده را باز کن → تب **Settings**
2. بخش **Build/Deploy** → فیلد **Root Directory** = `deploy/railway`
3. Save — Railway الان فقط این فولدر را build و deploy می‌کند.

---

## مرحله ۳ — Variables (متغیرهای محیطی)

تب **Variables** → این چهار مورد را اضافه کن:

| نام | مقدار | توضیح |
|---|---|---|
| `BOT_TOKEN` | توکن ربات از @BotFather | همان توکن فعلی |
| `ADMIN_IDS` | آی‌دی عددی خودت | مثل لوکال |
| `SOURCE_CHANNEL` | `MARKIZ_ARG` | کانال مرجع (پیش‌فرض هست، اختیاری) |
| `DATA_DIR` | `/data` | مسیر Volume برای ماندگاری DB |

> هرگز توکن را در هیچ فایل کامیت‌شده نگذار — فقط Variables.

---

## مرحله ۴ — ساخت Volume (ماندگاری دیتابیس)

بدون Volume، هر دیپلوی دیتابیس را صفر می‌کند:

1. تب **Settings** → **Volumes** → **+ New Volume**
2. Mount path = `/data`
3. Save

---

## مرحله ۵ — Deploy و بررسی لاگ

1. تب **Deployments** → آخرین دیپلوی → لاگ زنده:
   - باید ببینی: `🤖 ربات در حال اجراست...`
   - و بعدش لاگ‌های اسکن هر دقیقه.
2. اگر خطا بود (مثلاً InvalidToken)، یعنی Variable اشتباه است.

---

## مرحله ۶ — تست ربات در تلگرام

1. به @yas110gold_bot پیام بده: `/start` سپس `/settings`
2. دکمه‌ها را امتحان کن — پنل کامل لوکال را دارد.
3. `/now` → قیمت لحظهای؛ صبر کن فروش عوض شود → **پست به کانال** (هشدار خودکار ادمین حذف شده).

---

## مرحله ۷ — قوانین طلایی (خیلی مهم!)

### 🔴 فقط یکی! 
**هرگز نسخه‌ی لوکال و Railway را هم‌زمان روشن نکن.** دوتا ربات
هم‌زمان getUpdates تلگرام را تقسیم می‌کنند ⇒ دکمه‌ها بی‌جواب، پست‌های تکراری.
قبل از روشن‌کردن Railway، لوکال را خاموش کن و برعکس.

### 🔄 آپدیت کد
کامیت جدید روی `main` push شود ⇒ Railway خودکار redeploy می‌کند.

### 💸 مصرف منابع
Settings → **Usage**: CPU/RAM را زیر ۱GB نگه دار تا تریال زودتر تمام نشود.

### ⏹ توقف موقت
هر زمان خواستی ربات موقتاً خاموش شود: سرویس → Settings → **Pause Service**
(دیگر منابع مصرف نمی‌کند).

## عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| `InvalidToken` | `BOT_TOKEN` اشتباه — از BotFather دوباره کپی کن |
| `ADMIN_IDS` خطا | فقط عدد با کاما: `306652923,222222` |
| دکمه‌ها بی‌جواب | احتمالاً لوکال همزمان روشن است — خاموشش کن |
| دیتابیس بعد از دیپلوی صفر شد | Volume نساخته‌ای یا `DATA_DIR` ≠ mount path |
| ربات start نمی‌شود | لاگ دیپلوی: معمولاً Variable جا افتاده |
