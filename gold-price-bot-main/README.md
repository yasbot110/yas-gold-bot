# ربات قیمت طلا (طلای آبشده مارکیز) 🏆

ربات تلگرامی پایتونی که هر **۶۰ ثانیه** قیمت خرید/فروش طلای آبشده را از کانال
[@MARKIZ_ARG](https://t.me/MARKIZ_ARG) می‌خواند، در SQLite ذخیره می‌کند و به
**ادمین** گزارش می‌دهد. امکان انتشار دستی/خودکار قیمت در کانال انتخابی شما هم
دارد.

## ساختار پروژه

```
gold-price-bot/
├── bot/
│   ├── __main__.py     ← نقطه‌ی ورود: python -m bot
│   ├── config.py       ← خواندن .env و اعتبارسنجی
│   ├── scraper.py      ← خواندن t.me/s/MARKIZ_ARG + پارس پیام‌ها
│   ├── database.py     ← SQLite (آخرین قیمت‌ها + تاریخچه)
│   ├── formatting.py   ← قالب پیام‌ها (HTML فارسی، ارقام فارسی)
│   ├── jalali.py       ← تاریخ شمسی بدون کتابخانه
│   ├── persian.py      ← تبدیل ارقام و جداکننده‌ی هزارگان
│   └── bot.py          ← هسته: هندلرها + جاب هر دقیقه
├── parsers/            ← پروتوتایپ اولیه (مرجع)
├── data/               ← دیتابیس و لاگ (خودکار ساخته می‌شود)
├── .env                ← تنظیمات محلی (ساخته نکنید داخل گیت!)
└── requirements.txt
```

## دستورهای ربات (فقط ادمین)

| دستور | کار |
|---|---|
| `/start` | راهنما |
| `/now` | دریافت فوری آخرین قیمت از کانال مرجع |
| `/status` | وضعیت سرویس (آخرین دریافت موفق/خطا) |
| `/publish` | ارسال پست قیمت + دکمه به کانال انتشار |
| ⚙️ `/settings` → «📡 نام کانال» | تنظیم کانال انتشار |

## مدل قیمت

- از کانال مرجع **فقط «قیمت فروش»** خوانده می‌شود؛ کانال ریال می‌گوید و ربات همان لحظه ÷۱۰ کرده و **تومان** ثبت می‌کند.
- **قیمت خرید محاسبه می‌شود:** `خرید = فروش − کسر` (پیش‌فرض کسر: ۱۰۰٬۰۰۰ تومان).
- تغییر کسر فقط دستی است: ⚙️ `/settings` → «➖ کسر خرید» → عدد تومانی دلخواه را بفرست.
- همه‌ی قیمت‌ها با **ارقام انگلیسی** و واحد **تومان** نمایش داده می‌شوند (تاریخ و آی‌دی‌ها فارسی می‌مانند).
- پست کانال دو دکمه دارد: «🔴 فروش به ما» (راست) و «🟢 خرید از ما» (چپ) — فعلاً هر دو فقط به ربات لینک می‌دهند.

## رفتار خودکار

- هر `POLL_INTERVAL` ثانیه فقط قیمت فروش از کانال مرجع خوانده می‌شود.
- تغییر فروش → **اعلان فوری** به ادمین (⬆️/⬇️ + خریدِ محاسبه‌شده) و **پست جدید در کانال انتشار**
  (فروش ثابت → هیچ پستی نمی‌رود؛ بدون اسپم).
- **ساعات کاری انتشار: ۹:۳۰ تا ۲۰:۰۰ تهران** — بیرون از بازه پست خودکار نمی‌رود
  (`WORK_START_MIN` / `WORK_END_MIN`)؛ هشدار ادمین شبانه‌روزی است.
- روشن/خاموش کردن انتشار خودکار و تنظیم کانال: ⚙️ `/settings`.
- هر **۵ دقیقه** گزارش کامل به همه‌ی ادمین‌ها می‌رود (از پنل قابل خاموش‌کردن).
- تاریخچه‌ی همه‌ی قیمت‌ها برای نمودارهای آینده در `data/bot.db` ذخیره می‌شود.

## نکته‌های مهم

1. قیمت‌ها به **ریال** هستند و در پیام‌ها صریحاً «ریال» نوشته می‌شود.
2. کانال مرجع قیمت‌ها را با «اعتبار ۱ دقیقه» می‌فرستد؛ پس کوئری ۶۰ ثانیه معقول است.
3. برای انتشار در کانال خودت، اول ربات را **ادمین کانال** کن (اجازه‌ی Post Messages).
4. `.env` هرگز وارد گیت نمی‌شود — توکن ربات مثل رمز عبور است.
5. مرحله‌ی بعد (طبق نقشه): سفارش‌گیری از مشتری + سایت.
